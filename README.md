# YouTube Summarizer

Desktop application to summarize YouTube videos using AI.

## Download

Go to the [Releases](https://github.com/toussaintgarinat-crypto/youtube-summarizer/releases) page to download the latest `.app` file.

## Installation

1. Download the latest `YouTubeSummarizer.app.zip` from [Releases](https://github.com/toussaintgarinat-crypto/youtube-summarizer/releases)
2. Unzip the file
3. Move `YouTubeSummarizer.app` to your Applications folder
4. Double-click to launch

## Important: Architecture

**This `.app` is built for Intel Macs (x86_64).**

- **Intel Mac**: Works directly
- **Apple Silicon Mac (M1/M2/M3)**: Requires Rosetta 2

### Enabling Rosetta on Apple Silicon

If you have an Apple Silicon Mac and the app doesn't work, enable Rosetta:

```bash
softwareupdate --install-rosetta
```

Or right-click the app > Get Info > check "Open using Rosetta".

## Features

- Summarize any YouTube video
- AI-powered analysis
- Export summaries as images
- Local processing (your API key stays on your machine)

## API Key

You need an OpenAI API key. The app will prompt you to enter it on first launch.
